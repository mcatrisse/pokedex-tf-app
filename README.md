# Pokedex TF App

This project includes the required Terraform Files to deploy a `t3.micro` EC2 instance with the Pokedex angular app served via Nginx.
You can find the Angular project here: [https://github.com/mcatrisse/pokedex-angular-app](https://github.com/mcatrisse/pokedex-angular-app)


## Deploy TF resources

```bash
$ cd ./src
$ terraform init
$ terraform apply
```
